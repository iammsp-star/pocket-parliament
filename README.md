## 🎮 About

**Pocket Parliament** is an isometric macroeconomic simulation where you govern a developing nation. Every turn you make policy decisions — tax rates, sectoral investments, diplomatic alliances — and watch their ripple effects unfold across GDP, inflation, faction approval, and social stability.

Can you keep the economy growing, the factions happy, and survive until the next election?

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js 16 + React 19 |
| 3D Rendering | React Three Fiber + Three.js |
| State Management | Zustand |
| Animations | Framer Motion |
| Charts | Recharts |
| Styling | Tailwind CSS v4 |
| Language | TypeScript |

## 🚀 Run Locally

```bash
git clone https://github.com/iammsp-star/pocket-parliament.git
cd pocket-parliament/pocket-parliament
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
